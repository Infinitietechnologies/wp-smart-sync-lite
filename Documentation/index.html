Installation

Requirements: WordPress 6.5 or later and PHP 8.1 or later. A source checkout needs its Composer dependencies installed with composer install using the included lockfile. The account configuring SmartSync needs permission to manage WordPress settings.

Examples and screenshots may show an earlier interface. Follow the current field labels and your provider's current console when they differ.

Step 1: Download the Plugin

  1. Download the Plugin File: Download the plugin's .zip file from the official source.

Step 2: Access the WordPress Admin Panel

  1. Log in to WordPress Admin: Open your WordPress admin dashboard by visiting yourdomain.com/wp-admin.
  2. Navigate to Plugins > Add New in the sidebar menu.

Step 3: Upload the Plugin

  1. Click on the Upload Plugin button at the top of the Add Plugins page.
  2. Select the downloaded .zip file by clicking the Choose File button.
  3. After selecting the file, click the Install Now button to start the installation process.

Step 4: Activate the Plugin

  1. Once the installation is complete, click the Activate Plugin button to enable the plugin.
  2. After activation, a new menu named SmartSync will appear in the WordPress admin sidebar.

How to Generate Keys

AWS IAM Key

  1. Log in to the AWS Management Console: Visit AWS Console and log in with your credentials.
  2. Navigate to Security Credentials in the AWS Console.
  3. Go to the Security Credentials tab and click Create Access Key.
  4. Securely save the generated Access Key ID and Secret Access Key. You won’t be able to view the secret key again after closing this window.

DigitalOcean Bucket Key

  1. Log in to DigitalOcean: Visit DigitalOcean Cloud and log in with your account.
  2. Navigate to Spaces Object Storage > Access Keys from the left-hand menu.
  3. Click Generate New Key and provide a descriptive name for the key.
  4. Securely save the Access Key and Secret Key displayed. Like AWS, you won’t be able to view the secret key again.

Google Service Account Key (JSON)

  1. Log in to Google Cloud Console: Visit Google Cloud Console and log in with your Google account.
  2. From the top navigation bar, select or create a project where you want to create the service account.
  3. Navigate to IAM & Admin > Service Accounts from the left-hand menu.
  4. Click + Create Service Account at the top.
  5. Enter a name and ID for your service account, then click Create and Continue.
  6. Grant the service account the storage permissions needed for the operations you plan to use, including bucket creation and public bucket IAM changes if configuring those through SmartSync.
  7. Click Done to finish creating the service account. You will be taken back to the list of service accounts.
  8. In the list, find your newly created service account, click the 3-dot menu on the right, and select Manage keys.
  9. Under the Keys section, click Add Key > Create new key, select JSON as the key type, then click Create.
  10. Your browser will download a `.json` file containing your credentials. Store it securely — this is your service account key and should be treated like a password.

Bunny CDN API Key

  1. Log in to Bunny CDN: Visit Bunny.net and log in with your account credentials.
  2. Navigate to Storage: From the dashboard, click on Storage in the left sidebar menu.
  3. Create Storage Zone: Click the Add Storage Zone button and provide a name for your storage zone. Select your preferred region and click Add Storage Zone.
  4. Add Pull Zone: After creating the storage zone, navigate to the storage zone details and click on Connect Pull Zone or create a new Pull Zone. This will enable CDN delivery for your files.
  5. Access Account Settings: Click on your account name in the top-right corner and select Account Settings from the dropdown menu.
  6. Get API Key: In the Account Settings page, scroll down to find the API section. Click on Show next to the API Key field to reveal your API key, then copy it.
  7. Securely save your API Key. This key will be used to authenticate your WordPress plugin with Bunny CDN.

How to Configure

AWS Configuration

The plugin provides a wizard to simplify the AWS configuration process. Follow the steps below:

  1. Select Cloud Config: On the menu of SmartSync Settings, select Cloudconfig .
  2. Select AWS as the Provider: On the first wizard page, select AWS as the provider. Enter your IAM Access Key and Secret Key.
  3. Choose a Bucket: On the second page, select whether to use an existing bucket or create a new one:
    • If using an existing bucket, select it from the dropdown.
    • If creating a new bucket, enter the bucket name in the input field.
  4. Enable CloudFront (Optional): On the third page, decide whether to use CloudFront for content delivery. If enabled, the plugin will configure it for you.
  5. Finish Setup: Complete the setup on the final page, which displays a confirmation message indicating that the configuration is successful.

DigitalOcean Configuration

The plugin also supports DigitalOcean Spaces. Follow the steps below to configure:

  1. Select DigitalOcean as the Provider: On the first wizard page, select DigitalOcean as the provider. Enter your Access Key and Secret Key.
  2. Choose a Bucket: On the second page, select whether to use an existing bucket or create a new one:
    • If using an existing bucket, select it from the dropdown.
    • If creating a new bucket, enter the bucket name in the input field.
  3. Finish Setup: Complete the setup on the final page, which displays a confirmation message indicating that the configuration is successful.

Google Cloud Storage Configuration

Select Google Cloud and upload a service-account JSON file, or reuse the saved account when offered. Select an existing bucket or create a new one. New buckets use the US location; existing buckets retain the location returned by Google. SmartSync configures public bucket IAM for public delivery, so the account must permit that operation.

Cloudflare R2 Configuration

Select Cloudflare, enter the access key and secret, the R2 account storage endpoint, and the public CDN URL. The storage API endpoint and public URL are separate fields. Choose or create a bucket; SmartSync uses the auto storage region. CloudFront setup is only available for AWS.

Wasabi Configuration

Select Wasabi, enter the access key, secret, and bucket region before loading buckets. Choose an existing bucket or enter a new name in that region, then finish configuration.

Bunny CDN Configuration

Configure Bunny CDN to use its powerful edge storage and CDN capabilities for your WordPress media. Follow the steps below:

  1. Access WordPress Admin: Log in to your WordPress admin dashboard and navigate to the SmartSync menu.
  2. Go to SmartSync Cloud Config: Click on Cloud Config in the SmartSync menu to access the configuration wizard.
  3. Select Bunny CDN as the Provider: On the first wizard page, select Bunny CDN as your cloud storage provider. Enter the API Key that you copied from your Bunny CDN account settings.
  4. Select Storage Zone (Bucket): After authenticating with your API key, a dropdown will appear showing all available storage zones in your Bunny CDN account. Select the storage zone (bucket) you want to use for your WordPress media.
  5. Select Pull Zone: Choose the Pull Zone that is connected to your selected storage zone. The Pull Zone is the CDN endpoint that will deliver your content globally.
  6. Complete Setup: Click the Save Configuration button to finalize the setup. A confirmation message will appear indicating that Bunny CDN has been successfully configured.
  7. You're Done! Your WordPress site is now configured to use Bunny CDN for media storage and delivery. You can start syncing your media files to Bunny CDN from the Settings page.

Settings

The SmartSync settings page provides three tabs for managing your cloud storage configuration and syncing options. Below is an overview of each tab and its features.

1. General Tab

This tab contains tools for fetching analytics and clearing CloudFront cache (AWS only).

  • Fetch Analytics: Click this button to view:
    • Total storage used (in MB or GB).
    • Number of files in the cloud.
    • Storage counts and sizes; billing cost is shown as unavailable because SmartSync does not query provider billing.
  • Clear CloudFront Cache: Available only for AWS configurations. Click this button to request invalidation of the configured CloudFront distribution.

2. Media Tab

Manage your media files and cloud sync settings in this tab.

  • Use Cloud URL: Enable this switch to serve media files directly from the cloud instead of the site URL. This option is only available after syncing media to the cloud.
  • Automatically Delete Local Media After Upload: Enable this switch to remove local copies only after every file for an attachment uploads successfully and media CDN delivery is enabled with a valid URL. Failed uploads retain every local copy. This local cleanup keeps the cloud objects; deleting the attachment itself also deletes its tracked cloud objects.
  • Sync Local to Cloud Media: Click this button to upload all local media files to the cloud.
  • Sync Cloud to Local Media: Click this button to download all media files from the cloud to your local storage. Restore locally removed files before disabling media CDN, changing storage targets, or uninstalling SmartSync.

3. Assets Tab

Manage your website assets (e.g., JavaScript, CSS files) and cloud sync settings in this tab.

  • Use Cloud URL: Enable this switch to serve assets directly from the cloud instead of the site URL. This option is only available after syncing assets to the cloud.
  • Sync Local to Cloud Assets: Click this button to upload all local assets to the cloud.

On multisite, media synchronization stays inside the current site's uploads directory and excludes other sites' media. Site administrators can restore only file types allowed by WordPress; restoring shared assets requires network administrator permission.

Custom URL Configuration

The Custom URL configuration allows you to use a custom domain for serving content via AWS CloudFront. Follow these steps to configure and attach a custom domain with SSL:

Step 1: Access the Custom URL Settings

  1. Configure AWS with CloudFront first, then open SmartSync Settings > Custom CloudFront URL.

Step 2: Enter the Domain Name

  1. Enter the domain name you want to use in the provided input field and click the Generate Certificate button. Enter a hostname such as cdn.example.com, without a URL scheme or path.
  2. The plugin requests an ACM certificate and displays DNS records to add to your domain's DNS settings. Validation records can appear on a subsequent status check.

Step 3: Verify the DNS Records

  1. Add the displayed certificate-validation CNAME records and point the custom domain's CNAME to the configured CloudFront hostname.
  2. Wait for the DNS changes to propagate. The plugin will automatically verify the records after propagation. If a request fails, use Retry DNS Check.

Step 4: Attach the Domain to CloudFront

  1. Once the DNS records are verified, an Attach to CloudFront button will become enabled. Verification requires both an issued matching certificate and the correct CloudFront CNAME.
  2. Click the button to associate your custom domain with the CloudFront distribution.

Step 5: Complete Configuration

After AWS accepts the update, the custom domain becomes the active CDN URL. CloudFront deployment and DNS propagation may still need time before the domain serves traffic.

Deactivation and Uninstall

Deactivation cancels queued synchronization and keeps configuration. Uninstall removes SmartSync's local settings, credentials, queue, and offload metadata. It does not restore local files or delete remote objects. Restore any locally removed media before uninstalling.
