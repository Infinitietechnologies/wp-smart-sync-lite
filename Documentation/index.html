SmartSync Lite

Version 1.8.0 · WordPress 6.5+ · PHP 8.1+

Installation

  1. Install the SmartSync Lite ZIP in Plugins → Add New → Upload Plugin.
  2. Activate SmartSync Lite.
  3. Open SmartSync Lite → Cloud Config.

Use one edition at a time: Lite and Pro share plugin state. Restore offloaded media using Pro before switching away from a Pro-only configuration.

Provider credentials

Amazon S3

Create a dedicated IAM access key with the bucket and object permissions needed for your selected operations.

DigitalOcean Spaces

Create a Spaces access key and secret for the target Space and datacenter.

Wasabi

Create a dedicated access key and choose the bucket region.

Bunny Storage/CDN

Use your account API key. Choose an existing storage zone and its connected public pull zone.

Google Cloud Storage — Pro only

Preview only in Lite. No credentials are read or uploaded.

Connect storage

  1. Select Amazon S3, DigitalOcean Spaces, Wasabi or Bunny.
  2. Connect with your provider credentials.
  3. Select storage and save the connection.

Saving configuration does not transfer media. Lite uses direct storage URLs or a connected Bunny hostname.

Media synchronization

  1. Open Media and upload your files.
  2. Review progress and any errors.
  3. Enable cloud media delivery after successful synchronization.

Incremental uploads skip verified unchanged files; full resync uploads every eligible local media file. Restore downloads media locally. Optional local removal requires successful attachment uploads and enabled cloud delivery.

JS and CSS synchronization appears as a disabled Pro only preview.
